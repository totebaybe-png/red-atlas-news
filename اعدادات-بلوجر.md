# إعدادات بلوجر الاحترافية: Red Atlas News

كل الإعدادات دي في بلوجر من: **Settings** (القائمة اللي على الشمال).

## ✅ الجزء 1: نعمله دلوقتي

| القسم | الإعداد | القيمة |
|---|---|---|
| Basic | Favicon | ارفع `brand\favicon.png` |
| Privacy | Visible to search engines | **Off** (لسه مقفول لحد الإطلاق) |
| Permissions | Blog readers | **Public** |
| Posts | Max posts shown on main page | **10** |
| Posts | Image lightbox | **On** |
| Comments | Comment location | **Hide** |
| Email | Post using email | **Off** |
| Formatting | Time zone | **(GMT+00:00) UTC** |
| Meta tags | Enable search description | **On** |
| Meta tags | Search description | `Red Atlas News delivers breaking world news, live gold prices, and sharp market analysis. Fast, accurate, and independent.` |
| Crawlers and indexing | Enable custom robots header tags | **On** (القيم تحت) |
| Site feed | Allow blog feed | **Full** ⚠️ مهم: شريط Breaking وبلوكات الأقسام بيشتغلوا من الـ Feed |
| Site feed | Post feed redirect URL | فاضي |

### Custom robots header tags
| الخانة | تختار |
|---|---|
| Home page tags | ✅ all |
| Archive and search page tags | ✅ noindex |
| Post and page tags | ✅ all |

⚠️ **متفعّلش "Custom robots.txt" دلوقتي.** لو اتفعّل هيفتح الموقع لجوجل قبل ما يبقى جاهز.

---

## 🚀 الجزء 2: يوم الإطلاق (بعد شراء الدومين)

1. **Publishing** ← Custom domain ← `www.redatlasnews.com` ← ونعمل إعدادات DNS (هشرحها ساعتها).
2. **Publishing** ← Redirect domain ← **On** (يحوّل redatlasnews.com لـ www).
3. **HTTPS availability** و **HTTPS redirect** ← **On**.
4. **Privacy** ← Visible to search engines ← **On**.
5. **Crawlers and indexing** ← Enable custom robots.txt ← **On** ← والصق محتوى ملف `launch\robots.txt`.
6. **Google Search Console**: نضيف الموقع ونبعت `sitemap.xml`.
7. **Google Analytics (GA4)**: Measurement ID في Settings ← Google Analytics Measurement ID.
8. **Google News Publisher Center**: نضيف الموقع.
9. **AdSense**: بعد ما يبقى فيه محتوى كفاية والموقع يتأرشف.
